## 📌 Project Name
Fitness App

## 📝 Short Description
FitLog is a dark‑themed, no‑nonsense gym companion built with **Next.js** and **Tailwind CSS**.  
It allows users to browse workouts, add them to their daily plan, save for later, and track progress with live metrics.

---

## 🛠️ Technologies Used
- **Next.js (App Router)** → UI and routing  
- **Tailwind CSS** → Styling and responsiveness  
- **FitLog API** → Workout data integration  
- **React Hooks & State** → Dynamic updates  
- **Toast Notifications** → User feedback  

---

## ✨ 5 Key Features
1. **Responsive Design** — Works seamlessly on mobile, tablet, and desktop.  
2. **Workout Library** — Browse 12 lifts with images, categories, equipment, and stats.  
3. **Workout Details Page** — Full specs, instructions, and action buttons (Add to Plan / Save).  
4. **My Plan Page** — Track today’s plan with live metrics (Exercises, Minutes, Calories).  
5. **Interactive Navbar Badges** — Plan and Saved counters update instantly with user actions.
